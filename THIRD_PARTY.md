# Сторонние материалы

`widget/src/main/res/drawable-nodpi/yandex_*.png` — оригинальные погодные иконки
Яндекс Погоды. Права принадлежат Яндексу; лицензия Apache 2.0 проекта
на эти материалы не распространяется. Источник прогноза указывается отдельной подписью в интерфейсе.

Официальный источник: https://disk.yandex.ru/d/RMjLetZ7DVq2jg

Правила оформления: https://probki.s3.yandex.net/Guide_weather_full.pdf

Исходные PNG сохранены без изменения цветов, рисунка и пропорций. Приложение
выбирает контрастные светлые/тёмные варианты. Один набор иконок используется для обоих источников прогноза.

Координаты отдельных метеостанций запрашиваются в реестре ВМО OSCAR/Surface
и хранятся локально в SQLite. [OSCAR/Surface](https://oscar.wmo.int/surface/)
